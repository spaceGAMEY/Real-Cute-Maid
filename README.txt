АВТООТВЕТЧИК ДЛЯ TELEGRAM (юзербот на Telethon)
================================================

Отвечает всем, кто пишет тебе в личку. Текст меняешь командами в «Избранном».

ШАГ 1. Получи API_ID и API_HASH
  - Зайди на https://my.telegram.org, войди по номеру телефона.
  - "API development tools" -> создай приложение (название любое).
  - Скопируй api_id (цифры) и api_hash (длинный набор букв и цифр).
  BotFather и свой ID для этого бота НЕ нужны.

ШАГ 2. Получи SESSION_STRING (один раз, у себя, не на хосте)
  - Установи Python и выполни: pip install telethon
  - Запусти: python gen_session.py
  - Введи API_ID, API_HASH, номер телефона и код из Telegram
    (если включена двухфакторка, ещё и пароль).
  - Скопируй длинную строку, которую он выведет.

ШАГ 3. Заполни config.py
  - Вставь API_ID, API_HASH и SESSION_STRING в кавычки.

ШАГ 4. Загрузи на хост
  - Загрузи весь zip на хост и укажи команду запуска: python main.py
  - Зависимости: pip install -r requirements.txt
    (многие хосты ставят их сами из requirements.txt)
  - Хост должен быть для постоянно работающих программ (бот/воркер),
    а не для сайтов.

ШАГ 5. Управление
  Напиши в «Избранное» (Saved Messages):
    /set Привет! Отвечу вечером.   - задать текст автоответа
    /on  и  /off                   - включить / выключить
    /status                        - посмотреть настройки
    /cooldown 6                    - отвечать одному человеку не чаще раза в 6 часов
    /reset                         - забыть, кому уже отвечал
    /help                          - справка

ВАЖНО
  - SESSION_STRING = полный доступ к твоему аккаунту. Никому не отдавай,
    не выкладывай на GitHub.
  - Бот отвечает только в личных чатах, ботам и служебному аккаунту Telegram не отвечает.
  - Настройки хранятся в settings.json. Если хост стирает файлы при перезапуске,
    текст сбросится на стандартный, тогда просто снова отправь /set.
